Beige: Chess Tactics Trainer (iOS, live) Cognito, Lightsail, Lambda, DynamoDB, Terraform
  • Live on the iOS App Store. Designed a two-plane architecture that separates an anonymous, latency-critical read plane (Lightsail container serving a 2.95M-puzzle SQLite catalog) from a low-volume per-user write plane (API Gateway with a Cognito JWT authorizer, six Lambdas, DynamoDB).
  • Built the data pipeline: re-tagged the full Lichess puzzle dataset by replaying each solution with python-chess to derive motifs, pawn structure and game phase, instead of relying on crowd-sourced tags.
  • Costed Lightsail against Fargate with an ALB and chose Lightsail, cutting the planned always-on cost from about $40/month to about $10/month.
  • Built CI/CD on GitHub OIDC (no long-lived AWS keys), five required PR checks, and automatic deploys with a live post-deploy smoke test.
  • Diagnosed a production stale-deploy incident that silently returned empty results by comparing live and local API responses, then wrote the smoke test that now blocks the same failure.
ChessChat: Real-Time Video Chess Platform Terraform, ECS Fargate, Redis, DynamoDB, Cognito, CloudFront
  • Designed a three-tier VPC across three Availability Zones (public, private app, private data), with security groups allowing traffic only from internet to ALB to Fargate to Redis.
  • Split the application across two hosts: CloudFront and S3 for the static sign-in site, and ECS Fargate behind an ALB for the authenticated gameplay runtime, all in modular Terraform.
  • Kept live game state in Redis, with a background finalisation queue that saves each completed game to DynamoDB in one transactional write regardless of move count.
  • Built PR-gated CI (backend, frontend and Terraform checks required on main, no admin bypass) with OIDC-authenticated deploys, plus CloudWatch alarms and eight custom application metrics.
  • Analysed a $212/month AWS bill and found that VPC interface endpoints bill per Availability Zone, accounting for $89 of it. Documented the fixed and variable costs and shut the environment down on that basis.
Stock Screener & Telegram Bot Lambda, EventBridge, API Gateway, S3, Parameter Store, AWS SAM

  • Chose each service to fit the workload (Lambda over EC2, S3 over RDS, Parameter Store over Secrets Manager), keeping AWS charges under $1/month.
  • Stored API credentials in Parameter Store with IAM scoped to a single parameter path, and rejected bot requests from unrecognised Telegram chats.
  • Diagnosed a silent failure: a lapsed data subscription let the job report success on zero records. Specified the data validation and CloudWatch alarm needed to catch it.
SUDOKOO: AI Sudoku Scanner Amazon Bedrock, Lambda, API Gateway, CloudFront, S3
